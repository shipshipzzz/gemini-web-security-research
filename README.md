# Gemini 高级模型越权访问与配额边界研究

> 发现了一条低订阅用户绕过权限调用高级模型的服务端路径，且该路径上的调用不会被正常扣减配额。已通过 Google VRP 负责任披露，获得 **US$1,000 奖励**。

| 项目 | 内容 |
| --- | --- |
| 漏洞类型 | Broken Access Control / 业务逻辑漏洞 / 配额控制绕过 |
| 研究对象 | Gemini 高级模型的订阅授权机制、服务端路由与配额记账 |
| 我的角色 | 独立研究员——从发现到验证、证据整理到厂商沟通全程独立完成 |

## 核心发现

这个问题不只是"配额没扣"那么简单。实际上是高级模型的三层服务端控制之间存在缝隙：

1. **订阅权限没挡住**——低层级账户在请求高级能力时，服务端没有返回 permission denied 或 upgrade required，直接放行了。
2. **请求确实到了高级模型的处理链路**——响应中出现了高级能力特有的容量控制状态码，说明请求已经穿过了授权层，不是前端 UI 的显示问题。
3. **配额没有正常扣减**——反复测试后，对应的高级配额计数器纹丝不动；而同一时间用正常 UI 走同样的操作，配额扣减完全正常。

本质上是 **Authentication → Entitlement Authorization → Capability Routing → Quota Accounting** 这条链路上的决策结果不一致：用户身份是合法的，但服务端在高级能力被选中和执行时没有重新校验订阅级别，后续记账也没覆盖这条路径。

## 证据链

| 验证阶段 | 预期行为 | 实际观察 | 说明 |
| --- | --- | --- | --- |
| 订阅权限校验 | 低层级会话在入口被拒绝 | 没有被拒绝 | entitlement gate 没生效 |
| 高级能力路由 | 未授权请求不进入高级处理链路 | 返回了高级能力特有的容量状态 | 请求已穿过授权层 |
| 配额记账 | 进入处理链路后应扣减对应配额 | 反复测试后配额不变 | 路由放行了但计量没跟上 |
| 正常 UI 对照 | 合法请求正常扣减 | 对照组扣减正常 | 排除"计数器本身就不更新"的可能 |

需要说明的是：容量响应能证明请求进入了高级能力的下游处理路径，但单凭它不能证明完成了一次完整推理。越权的结论是靠订阅身份、路由信号、权限拒绝缺失、可重复性和配额对照综合得出的。

## 技术方法

- 逆向 Gemini Web 客户端的请求构造和响应解析逻辑，搞清楚哪些是前端门控、哪些才是真正的服务端授权。
- 用高、低两个订阅层级做差分测试——只改能力选择参数，其他上下文保持一致。
- 按"基线 → 正常 UI 对照 → 越权路径 → 配额复核"的顺序做最小变量实验。
- 把授权状态、路由信号、配额快照整理成结构化数据，写代码自动检测异常关联。
- 原始报告和请求细节分级保管，公开仓库里不含可直接利用的字段或脚本。

## 可运行的证据分析器

仓库里有一个零依赖的 Node.js 分析器，可以离线跑三项检测：

- 低订阅账户是否越过 entitlement gate 到达了高级能力的下游阶段
- 越权路径上是否缺少正常对照组中应有的配额扣减
- 专用计数器和关联计数器之间是否存在归属不一致

需要 Node.js 20+。

```bash
npm test
npm run analyze
```

示例输出：

```text
F-01 跨层级授权边界
  高级能力 entitlement: absent
  实际到达阶段: capacity-control
  检出异常: cross-tier-authorization-bypass

F-02 配额约束对照
  Pro: 对照 -1，越权路径 0
  Thinking: 对照 -5，越权路径 0
  检出异常: 2

综合判定
  cross-tier-access-with-missing-metering
```

分析器只读取脱敏后的 JSON 快照，不联网，也不包含接口地址、认证凭据或可操作的利用逻辑。

## 项目难点与个人贡献

- Gemini 前端请求经过压缩和多层嵌套，没有公开的协议文档，需要自己逆向还原能力选择的完整链路。
- 关键洞察：身份认证通过 ≠ 高级能力授权通过。问题不在登录，而在服务端对订阅级别的二次校验缺失。
- 用高低订阅账户对照 + 重复请求 + 前后配额快照来构建证据链，而不是光靠 UI 截图下结论。
- 把手工研究过程转化为带输入校验和单元测试的 JavaScript 分析工具，让证据可复核。
- 从发现到 VRP 报告、影响阐释、负责任披露全程独立完成。

## 简历表述

> 独立发现 Gemini Web 端跨订阅层级的高级模型越权调用路径，定位到服务端 entitlement 授权、能力路由与配额记账之间的控制不一致；通过 API 差分与最小变量对照实验构建证据链，编写 JavaScript 分析器自动关联授权绕过与计量缺失，完成负责任披露并获得 Google VRP US$1,000 奖励。
